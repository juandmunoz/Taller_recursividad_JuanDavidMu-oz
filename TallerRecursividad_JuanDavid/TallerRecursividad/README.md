# Taller de Recursividad

Solución en Java de los 14 ejercicios del taller de Estructuras de Datos.

## Requisitos
- Java 17 o superior
- Maven 3.8 o superior (opcional si se ejecuta desde NetBeans/IDE)

## Ejecutar con Maven

```bash
mvn clean compile
mvn exec:java
```

## Estructura

- `Recursividad.java`: contiene las funciones recursivas de los 14 ejercicios.
- `Main.java`: menú de consola para probar cada ejercicio.
- `pom.xml`: configuración Maven.

## Ejercicios incluidos

1. Factorial.
2. Invertir un número.
3. Sumatoria 
4. Suma de los dígitos.
5. Sumatoria hasta 
6. Potencia.
7. MCD mediante algoritmo de Euclides.
8. Copiar una cadena.
9. Cociente de división mediante restas sucesivas.
10. Multiplicación mediante sumas sucesivas.
11. Suma de los elementos de un arreglo.
12. Suma de los elementos de una matriz.
13. Serie de Fibonacci.
14. Función de Ackermann.

Todas las operaciones principales solicitadas están implementadas mediante funciones recursivas.
